## 设计决定

- 测试用 Node 内置的 `node:test`，不引入测试框架，符合“能用内置模块就不加依赖”。
- 模型接口的测试用本地 HTTP 服务而不是替换 `fetch`，走真实的网络路径，能发现请求头、URL 拼接这类问题。
- 测试不访问真实接口、不读本机 `.env`；真实模型的验证留在 `examples/` 和 `npm run smoke`。
- 循环只依赖 `AgentModel` 接口，真实客户端在第 4 步实现它即可，循环代码不用改。
- 停止检查放在工具执行之后、下一次调用模型之前，收尾说明附加在还没发出的工具结果上。
- 工具调用按顺序执行，并行执行留到以后需要时再加。
- 模型客户端暂不发送 `tools` 字段，留给第 4 步。
