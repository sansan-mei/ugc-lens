# 多轮对话

- 日期：2026-11-04
- 关联步骤：roadmap 第 2 步

## 改动内容

- 新增 `examples/02_multi_turn.ts`：命令行多轮对话，支持 `/history`、`/reset`、`/exit`，每轮打印本轮和累计 token。
- `package.json` 新增脚本 `multi`。

## 设计决定

- 不改动 `src/llm/client.ts`：多轮对话只是调用方维护 `messages` 数组，客户端不需要知道“第几轮”。
- 请求失败时撤回刚加入的用户消息，避免历史里留下没有回答的提问。
- 用管道输入时，readline 在读完输入后会提前关闭，再调用 `rl.prompt()` 会抛 `ERR_USE_AFTER_CLOSE`。用 `closed` 标记跳过关闭后的提示。

## 验证

- `npm run typecheck` 通过。
- 通过管道输入两轮问题测试：第二轮问“我刚才说我最喜欢哪个城市”，模型答对“成都”；input token 从 48 增长到 69，`/history` 显示 5 条消息。
- 首次测试时发现上面的 readline 关闭问题，修复后通过。
- 交互式输入未在自动化环境中测试，需要手动运行 `npm run multi` 确认。
