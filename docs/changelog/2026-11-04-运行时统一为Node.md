# 运行时统一为Node

- 日期：2026-11-04
- 关联步骤：无

## 改动内容

- `package.json`：`chat`、`models` 改回用 `node` 运行；`test:node` 改名为 `smoke`（用 Node 运行示例做冒烟检查）。
- `AGENTS.md`：运行时一节改为“开发和运行都用 Node，Bun 只用于安装依赖”；检查命令同步更新。
- `docs/architecture.md`：技术选型表中的运行时一行同步修改。

## 设计决定

- 以兼容为主：开发时就用和用户相同的运行时，避免“开发时能跑、用户那里不能跑”。
- Bun 仍用于安装依赖（速度快，已有 `bun.lock`），不参与运行。
- `src/config.ts` 中对 `process.loadEnvFile` 的存在性判断保留：有人用 Bun 运行时不会直接报错。
