## 设计决定

- 采用官方 SDK 处理协议、握手、现代与 2025 客户端兼容及取消，不自行编写 JSON-RPC 传输。
- 服务仅使用 stdio，不启动 HTTP 监听；stdout 严格留给协议，诊断走 stderr。普通 CLI 命令动态加载 MCP 实现。
- 每个服务实例独立维护数据集和追问历史；模型配置按需读取，握手和工具发现不要求 API key。
- 宿主可直接调用数据查询工具自行分析，也可通过 analyze、ask 使用 ugc-lens 配置的模型，避免强制嵌套问答。
- 同一追问会话绑定同一数据集，禁止并发修改历史；请求取消、宿主断开、EOF 或退出信号传递给底层请求。
- 只提供配置示例和技能文件，不改动用户的宿主配置。
