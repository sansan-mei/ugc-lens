## 设计决定

- 保留底层 `AgentTool` 接口，`defineTool` 只是在它上面包一层。循环不依赖 Zod，测试里手写的工具也不用改。
- 校验放在 `defineTool` 生成的 `execute` 里，而不是循环里：循环只需要识别 `ToolArgumentError`，不需要知道 Zod。
- 用 `io: 'input'` 生成 JSON Schema，带默认值的字段对模型是可选的。
- 去掉 `$schema` 和自动生成的安全整数边界：前者部分提供商会拒绝，后者对模型没有意义还占 token。
- 参数校验不做类型转换（例如不把字符串 `"3"` 转成数字）。先让模型收到明确的错误并自己修正；如果实际使用中这类错误很多，再考虑用 `z.coerce`。
- 未知参数默认忽略（Zod 对象的默认行为），不报错。
- Zod 的错误信息保持英文，不调用 `z.config` 切换语言：那是全局设置，作为库不应修改。参数名、收到的值和整体说明是中文。
- `calculate` 用结构化参数（运算类型 + 两个数），不解析表达式字符串，避免引入表达式解析器，也绝不用 `eval`。
