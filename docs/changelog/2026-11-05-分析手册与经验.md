## 设计决定

- 业务规则按共同规则、追问、分块总结、合并分节；协议和引用校验保留在代码里。一次分析及整段对话使用固定规则，编辑仅影响下次分析或新对话。
- 自动经验只记录代码能核实的运行信息，不额外调用模型反思，也不保存完整私人问答；模型提出的经验标成候选，并绑定数据集和证据 ID。
- 模型只有规则提案工具，应用由用户通过 CLI 执行。待审修改保留基准指纹，防止覆盖人工编辑。经验写入失败返回警告并保留已生成结果。
- 没有新增依赖。保持核心 API 默认无经验文件写入，减少已有集成的副作用。
