## 设计决定

- 参考的项目：Jigsaw sensemaking-tools（话题加引用摘句、并发上限、自我检查）、TopicGPT（生成 → 精炼合并 → 分配 → 纠正）、Talk to the City（论点聚类、两层主题）、LLooM（概念带纳入标准）、Anthropic Clio（属性抽取后分层聚类）、LIDA 和 Data Interpreter（写代码分析表格）、本机的 BettaFish（向量聚类后抽样、微调情感模型、多 Agent 报告）。
- 采用“先分块找观点，再合并精炼”。每条观点带纳入标准，主题最多两层，引用校验和支持条数由代码完成。
- 不做 TopicGPT 的逐条分配：每条内容都要再过一遍模型，调用次数和块数一样多。
- 不做模型自我检查：调用次数翻倍，以后作为可选项。
- 继续不做向量聚类：要多配一个嵌入模型，各家提供商支持情况不一样。
- 通用化范围选“通用文本记录”，不做数字表格分析。时间放在 9.2、9.3 之后单独一步（9.5），避免拖住第一版；为了不返工，9.2 的提示词不假设“视频评论”，分析方向做成可配置。
- 新步骤编号用 9.5，不重新编号后面的步骤，因为旧的更新记录里引用了第 10～13 步。
