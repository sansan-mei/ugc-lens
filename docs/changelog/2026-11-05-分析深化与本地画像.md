## 改动内容

- `src/analysis/batches.ts`：共享分批语义评估，校验 ID、参数、遗漏、预算、取消与强制工具调用兼容回退。
- `src/analysis/topics.ts`、`src/tools/data/deep_analysis.ts`：主题发现后逐条多标签归类，代码计算样本内占比；也可直接提供主题和纳入标准。对话、ask 和 MCP 均可调用，保存完整逐条 JSON。
- `src/analysis/business.ts` 与 `playbook/business.md`：可选商业分析，机会附真实摘句、假设、验证动作、投入及优先级；无证据不凑数，不自动估算 ROI。
- `src/analysis/coverage.ts`、`content_timeline.ts` 及报告：记录导入和模型处理覆盖，按内容隔离弹幕窗口与字幕，输出中文表格；无字幕不猜测画面或因果。
- `src/sentiment/index.ts`：增加混合情感、反讽及评价对象字段，混合情绪单列，不因均值为零归入中性。
- `src/memory/profile.ts`、`src/cli/profile.ts`：可选本地画像，持续增量学习用户自述与候选背景，支持来源、作用域、修订、过期标记、用户纠正、确认、删除、关闭、清空和指定历史导入。支持命名画像及项目隔离，不内置任何真实用户资料。
- 对话、ask、MCP 和代码 API 接入新能力；画像通过工具结果读取，不改变 system prompt 或伪造历史消息。额外学习用量单独返回，学习失败保留正常回答。
- 默认手册版本 3，情感、主题、痛点、商业机会及对比优先用表格，关键数字加粗，长解释及步骤用列表。更新 README、架构、路线图、宿主技能指引，版本升至 0.0.8。

## 设计决定

- 精确数量指对实际逐条分类结果的代码统计，不意味着模型的语义判断必然正确；主题比例分母为成功处理条数，多标签允许总占比超过 100%。无法归类、不确定、失败和跳过分别记录。原报告估计支持数仍标“约”，不能与逐条统计混用。
- 主题发现阶段的模型用量独立返回，逐条阶段默认软预算 30000。商业分析按原文逐条保留机会，引用数不当作独立用户或市场规模。
- 覆盖记录区分成功总结块与逐条标签核验，重复正文只是特征，不判为水军。时间轴支持分页、正文截断标记和字幕省略数；极长稀疏时间轴不分配大量空窗口，峰值状态为 null。
- 画像默认关闭；只从明确用户发言增量学习，不读取模型或工具结果作为操作者经历。用户手动确认的条目优先，推断保留候选状态；删除清除相关修订并保留不可逆摘要，阻止同引用换键重学。写入采用进程锁和临时文件重命名，冲突返回错误而非覆盖。
- 默认画像为本机当前账户的 `~/.ugc-lens/user.md`；多人共用系统账户可用 `UGC_LENS_PROFILE` 分离，项目条目按工作目录隔离。原始历史不自动持久化；指定 TXT 导入限制文件大小、段数与字符数。
- 固定报告加入代码计算的覆盖和时间轴表；逐条主题、情感、商业分析依需求调用，不默认增加这些模型请求。已有自定义 playbook 不覆盖。
