## 设计决定

- 先按 endpoint、接口和模型建立能力适配，再应用缓存参数；不能给所有模型发送同一套字段。Claude 原生 Messages 与 OpenAI Responses 属于计划中的接口扩展，当前尚未实现。
- 提供商 KV 前缀缓存与本地阶段结果复用分开。前者仍生成新答复，后者需要严格失效、隔离和来源记录；不缓存整段自由对话或写入副作用。
- 区分 ugc-lens 内部调用与 MCP 宿主外层调用，不承诺控制 Codex/Claude Code 宿主缓存，也不在本步骤引入订阅账号授权。
- 默认不为缓存发送额外预热/保活调用，实际读写价格、TTL 与命中以对应模型和接口为准。
