## 设计决定

- 视频 ID 从路径取（文件里没有）：BV 号优先，其次目录名末尾的 av 号；都没有就报错。
- 弹幕没有平台 ID，用 `内容ID:dm:序号` 生成，同一文件重复读入得到相同 ID，后面引用证据时可以稳定指向。
- 原文不清洗，`text` 保留原样；空字符串的描述、AI 总结视为没有。
- 数据集 ID 用文件绝对路径的 sha256 前 12 位：同一文件更新后 ID 不变，第 10 步监听目录时可以据此覆盖旧结果。
- 文件识别用白名单而不是按内容猜，与 media_crawl 的文件名约定保持一致；暂不支持的平台给出明确提示。
- 放弃按平台拆成多个数据集类型：所有平台共用一个格式，平台差异放在可选字段里（`video_time_sec`、`danmaku_mode` 等）。
