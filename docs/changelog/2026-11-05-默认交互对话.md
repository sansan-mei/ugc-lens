## 设计决定

- 对话直接调度领域工具，用户不必选择 ask、watch 或 analyze；查询工具共享内存中的数据集，保持原有历史与工具结果顺序不变式。
- 监听属于会话而非单次请求，启动后立即返回以支持继续对话；每个目录使用独立任务文件，防止恢复其他目录的未完成任务。
- 一次会话只启用一个目录监听，退出时取消分析并等待清理；对话历史暂不跨进程保存。
- 不增加依赖，不改变现有 Agent 循环。
