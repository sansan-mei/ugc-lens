# 默认学习用户关注点

- 日期：2026-11-05
- 关联步骤：roadmap 第 15 步

## 改动内容

- 版本升至 0.0.9，默认手册版本 4。
- 本地关注点学习默认开启，保留用户显式关闭状态；核心 API 未传 memory 时仍不启用。
- 新增 `hasLearningSignal`，单纯发文件、常规分析、寒暄和简单继续不调用学习模型，也不能通过 record_profile 凭空生成画像。
- 用户附带要求、主动追问中的关注维度和明确自述才作为学习来源，提取模型只接收当前用户发言，不接收模型回答、工具结果或数据集。
- 同步基础提示词、CLI 帮助、README、架构、路线图和宿主指引。

## 设计决定

- 记录“用户关注价格争议”之类的实际关注点，不能从“为什么他选择考公”推断“用户准备考公”。推断仍标候选，项目主题隔离，用户修正优先。
- 无关注信号时既不写记录，也不花额外模型 token；有信号但模型没有发现可复用要求时提交空数组，不强凑画像。
- 0.0.8 已由自动发布流程发布；本次用户补充作为 0.0.9 补丁发布，不覆盖已发布版本。

## 验证

- 新增文件/常规操作不学习、附带要求和追问产生信号、仅传用户原文及默认开启/保留关闭状态的回归用例。
- `npm run typecheck`、`npm test`（382 个用例）和 `git diff --check` 全部通过；使用假模型与本地 HTTP 模拟，不调用真实模型。
- 未在本机运行打包、构建或真实模型 smoke；推送后由既有 GitHub Actions 执行发布检查。

## 后续

- 安装新版本验收实际关注点提取质量；用户可随时查看、纠正、删除或关闭。
