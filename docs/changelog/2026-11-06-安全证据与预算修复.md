# 安全证据与预算修复

- 日期：2026-11-06
- 关联步骤：roadmap 第 15.5 步

## 改动内容

- `src/config.ts` 独立解析项目 `.env`，继承全局/进程凭证前检查可信端点及密钥环境变量绑定；`src/cli/init.ts` 使用独立配置对象，不污染进程环境。
- 新增 `src/dataset/evidence.ts` 统一字幕证据身份与回查；时间轴在无弹幕时也能返回字幕，`get_feedback`、引用校验、总结摘句和报告共用证据规则。
- `src/ingest/mapping.ts`、`infer.ts`、`apply.ts` 支持仅字幕来源，校验有效时间范围，记录字幕源状态、导入和失败数量，避免零段导入却显示命中率 100%。
- 导入重复父评论继续访问新增回复，子回复继承内容归属，显式直接父 ID 优先于容器父 ID。分块保留跨视频同文评论及其回复，无回复的同文组也保留成员身份；大型组按单块上限拆分。
- 回复文本保留称呼，压缩后附直接父 ID、根 ID 和内容归属；未知/未列出目标明确标记，过滤保留被其他回复指向的父节点。覆盖记录与报告单独展示字幕处理阶段。
- 拒绝缓存按源文件路径和数据摘要隔离；强制重新识别成功清除旧拒绝，旧版无摘要拒绝不再跨同结构文件泛化。
- 新增 `src/agent/usage.ts`，通过任务上下文共享外层、导入、内层分析、画像学习、重试和收尾用量。API、CLI、MCP、对话和后台分析接入；后台失败/取消的用量快照保存至任务存储。
- 架构、提供商配置和路线图同步更新，第 15.5 步六项标记完成。保留本次开始前已有的文档、协作规则和模型客户端测试改动。

## 设计决定

- 保留整体架构，修复模型输入之前的信息丢失，不增加 Agent；正文事实与观众互动使用不同分块类型。
- 项目配置不能自行授权继承凭证改端点；可信参数或进程环境可显式绑定。地址按完整字符串去除末尾斜杠比较，不扩大到整个域名。
- 证据完整性优先于把重复评论无限压缩；来源保留后可能需要更多字符预算，超出时仍明确记录抽样范围。
- 任务默认软预算 100000 token，已在途调用可超出，最多一次额外 Agent 收尾；嵌套阶段不能扩大外层预算。画像学习没有豁免。未知用量保留未知，字符估算单列并参与预算检查，不当作账单；不包含 MCP 宿主用量。
- 旧 `usage` 字段保持阶段口径，新增 `task_usage` 承载任务总量；MCP 使用结构化结果返回账本，保留既有文本响应格式。后台每个文件独立建账，避免继承启动监听那轮对话的账本。
