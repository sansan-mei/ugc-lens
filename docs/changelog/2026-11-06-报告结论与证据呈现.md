## 改动内容

- 新增 `src/pipeline/insights.ts`：读取候选主题所附原文、类型、内容归属及直接父回复语境，综合为最多六项重要发现，包含分组证据、反例/分歧、边界、意义和待验证事项。

- `src/analysis/content_timeline.ts` 支持从全部窗口选择关键窗口，报告附录保留完整时间窗口表，每窗的字幕和弹幕仍为有上限的摘录。

- 补充 `test/pipeline/insights.test.ts`，更新报告、流水线和数据工具回归；同步架构与路线文档。

## 设计决定

- 使用一次原文证据综合补足分析层，不逐块增加自检调用。只使用已有主题引用的有限正文，不假称全量重新分类。
- 每个支持或分歧组独立保留引用，避免统一按点赞取前三条而丢失某一方。任何一条引用 ID 未提交或摘句不是原文时，拒绝整项发现，不保留缺失一侧后的结论。
- 代码保证引用身份及逐字摘句匹配；标题是否被证据充分支持仍属模型语义判断，不把引用校验通过宣传为结论正确。
- 综合失败、截断或预算耗尽不阻断资料导出，但首页明确尚未形成有效核心发现。成功综合后候选主题仍保留在代码 API 返回结果中。
