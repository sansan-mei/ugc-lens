# 测试隔离用户主目录

- 日期：2026-11-06
- 关联步骤：无

## 改动内容

- `test/helpers/env.ts` 的 `isolateEnv()` 额外创建空的临时主目录，把 `HOME`、`USERPROFILE` 指向它，结束时恢复并删除；返回值新增 `home`。
- `test/config.test.ts` 新增回归：隔离后 `homedir()` 与 `globalConfigPath()` 指向临时目录，且读不到任何全局模型配置。

## 设计决定

- 在共用的隔离函数里处理，而不是逐个给 `loadLlmConfig` 传 `homeDir`：所有使用 `isolateEnv` 的测试都会默认读取用户主目录，统一隔离可避免以后新增测试再次读到本机配置。
- `os.homedir()` 在类 Unix 系统上优先读取 `HOME`，Windows 读取 `USERPROFILE`，两者都设置。

## 验证

- 修改前在已有全局配置的机器上运行 `test/config.test.ts`：13 项通过、6 项失败（原有 5 项与新增回归）。
- 修改后不改动 HOME 直接运行全量测试：453 项全部通过；`npm run typecheck`、`git diff --check` 通过。
