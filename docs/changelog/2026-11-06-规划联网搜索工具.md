## 设计决定

- 工具层用现有 `defineTool` 自行实现，只引用搜索后端 SDK 和正文抽取库：agentic 已归档，LangChain 依赖过重，duck-duck-scrape 依赖页面抓取且长期未更新。
- 搜索后端首批选 SearXNG（自建、免费）和 Tavily（托管、有官方 SDK）；DashScope 内置联网搜索不返回可引用的来源，不作为主方案。open-webSearch 和 mcp-searxng 是 MCP 服务，当前没有 MCP 客户端，只作参考。
- 默认关闭，固定分析流水线不联网，MCP 需单独开启，以保持报告可复现并减少网页注入面。
- 网页内容视为不可信数据；联网后的副作用工具必须审批，并防护 SSRF。
- 外部引用与数据证据分开命名和呈现，外部资料不进入统计分母。
