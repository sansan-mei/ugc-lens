## 设计决定

- 轻量技能不依赖本包和模型 key，脚本只用 Node 内置模块并支持 Node 18，安装技能即可使用；因此不从 `src/` 导入，编号规则用测试与导入器对照，防止两边分叉。
- 计数只来自正则匹配，模型估计须标明“about”；核验只证明 ID 存在、摘句逐字出现，不把它说成解读正确。
- 真实 B 站归档试跑后改为默认展开嵌套回复并记录 `parent_id`：只取顶层时 80 条，展开后 1025 条。
- 引号内的方括号（B 站表情）不当作引用；相邻 `[a][b]` 逐个核对，不再按 Markdown 引用链接跳过。
- 不提供自动安装命令，沿用“不修改用户宿主配置”的约定，安装交给 `npx skills add`。
