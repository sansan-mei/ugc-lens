# Animate 界面重构

- 日期：2026-11-10
- 关联步骤：roadmap 第 19 步

## 改动内容

- 用 React、Animate UI、Tailwind CSS、Motion 重写本地网页，源码放在 web/；使用真实的 Animate UI 标签页、Dialog、Drawer、Button、CountingNumber 和 Fade。
- 保留概况统计、SVG 图表、原文检索、报告引用与详情；保留全局 Key、原生选择框、上传和拖放。
- Vite 输出 ui/ 静态资源，随 npm 发布；前端依赖为精确版本的开发依赖。类型检查包含独立 web/tsconfig.json。
- 静态服务支持构建后的哈希资源路径，拒绝任意路径读取；测试使用隔离静态目录。

## 设计决定

- 按用户新要求放弃无框架前端，使用 Animate UI 真实组件而非只模仿动画。
- 页面以查看数据和检查原文为主，浅色毛玻璃卡片；动画限于切换、进入和选择反馈。
- 脚本 CSP 仍只允许同源；样式允许内联，以兼容 Animate UI 的样式注入与动画。
