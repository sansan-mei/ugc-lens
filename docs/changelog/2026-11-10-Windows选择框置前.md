# Windows选择框置前

- 日期：2026-11-10
- 关联步骤：无

## 改动内容

- `src/ui/picker.ts`：Windows 原生文件选择框改为先显示透明的置顶宿主窗口（标题为选择提示，任务栏可见），再用 `AttachThreadInput` + `SetForegroundWindow` 借用前台窗口线程的输入状态把宿主设为前台，然后以它为 owner 弹出 `OpenFileDialog`，结束后关闭宿主。
- PowerShell 脚本改用 `-EncodedCommand`（UTF-16LE Base64）传入。
- `test/ui/picker.test.ts`：解码脚本断言内容；新增回归测试，检查置顶宿主显示、取得前台、Win32 声明失败兜底均在弹框之前。

## 设计决定

- 用户在 Windows 上反馈：界面提示“请在系统文件选择框里选择文件”，但对话框被浏览器挡住。原因是弹框的 PowerShell 是后台进程，受 Windows 前台锁限制；原先以从未显示的隐藏置顶窗体作 owner 不足以压过前台浏览器。
- Win32 声明含双引号，经 `execFile` 拼进命令行后容易被转义破坏，因此改用 `-EncodedCommand`。
- `Add-Type` 编译 Win32 声明可能被系统策略（如受限语言模式）拦截，放在 `try/catch` 中，失败时仍弹出对话框。
- 未采用模拟按 Alt 键取得前台的做法：会触发浏览器菜单栏等副作用。
