## 设计决定

- 不引入前端框架和图表库：图表只有条形、柱状、面积、环形四种，SVG 字符串足够；不增加依赖和包体积，前端模块可在 Node 测试中直接导入。
- 安全：只监听 127.0.0.1；令牌放在 `#` 片段并在前端移出地址栏；Host 必须是本机端口，带 Origin 时必须同源；文件按真实路径限制在启动目录内；严格内容安全策略，不用内联脚本和 style 属性，所以图表颜色都走 CSS 类。
- 视觉方向按用户指定网站的浅色毛玻璃风格（浅底彩色光斑、半透明卡片、胶囊按钮、系统字体），页面结构按“监看与查阅”设计，不做营销式首屏。
- 对话、一键分析放到第二阶段：需要模型配置，第一阶段先保证不配置 key 也能看图表、原文和报告。
