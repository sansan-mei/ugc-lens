## 设计决定

- 需要模型判断的步骤交给宿主，ugc-lens 只做确定性步骤，因此宿主模式全程不读取模型配置；数量只来自真实检索或标明估计。
- 入口用命令行而不是新增 MCP 工具：技能在任何能执行 shell 的宿主里都可用；MCP 的数据工具在命中内置或缓存规则时本来就不需要 key。
- 宿主写的映射规则复用 `mappingSchema` 与 `applyMapping` 校验，通过后写入同一映射缓存，之后完整流水线和 MCP 也能直接使用。
- 内置规则须试转换无错误、无遗漏数组且有内容才采用；`useCache: false` 时跳过，保留强制重新识别的语义。
- 分块沿用 `planChunks`，只把块内编号换回原 ID，保证宿主模式与完整流水线的覆盖、抽样一致。
- 放弃 MCP sampling（由服务向宿主请求模型）：主流宿主支持不稳定。
