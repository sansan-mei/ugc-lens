# 密钥只存全局与界面文件选择框

- 日期：2026-11-10
- 关联步骤：roadmap 第 19 步（第一阶段）；docs/providers.md 第 4 节

## 改动内容

- 密钥只保存在全局配置：`loadLlmConfig`、`loadWebConfig` 不再读取项目目录的 `.env`；项目 `.ugc-lens/config.json` 写 `api_key` 时报错并提示迁移到 `~/.ugc-lens/config.json`（错误信息不含 key）。`init` 不再从当前目录 `.env` 读取已有 key，提示文字同步。删除 `loadDotEnv`，新增 `rejectProjectSecret`。
- 本仓库示例脚本改为 `node --env-file-if-exists=.env` 载入仓库根目录 `.env`，开发流程不变。
- 界面选择文件：新增 `src/ui/picker.ts`（系统文件对话框）、`/api/pick`、`/api/upload`；启动目录外的文件可以通过选择框或拖放打开；最近打开记录存在全局 `~/.ugc-lens/ui/recent.json`。报告页可打开任意位置的 Markdown（浏览器选择的报告只在页面内渲染，不上传）。
- 概况的宿主模式结果同时查找启动目录和数据文件所在目录。
- 文档：README“配置模型”、docs/providers.md、AGENTS.md 密钥规则、architecture 第 2.1 节。

## 设计决定

- 用户要求密钥存全局、不存当前目录。项目目录可能被提交或共享，`.env` 在当前目录生效也会让同一命令在不同目录行为不同。项目配置仍可改提供商和模型等非密钥设置。属于不兼容变化：之前把 key 放项目 `.env` 的用户需运行 `ugc-lens init` 或改用进程环境变量。
- 浏览器的文件选择只能拿到内容，拿不到路径；本地服务直接弹系统对话框可得到真实路径，保持数据集 ID 与宿主模式标注结果一致。无图形环境时退回上传。

## 验证

- 浏览器实测：无图形环境下“选择文件”退回浏览器选择，上传启动目录外的 B 站文件后概况正常；报告页打开目录外 Markdown，引用可点；注入假对话框验证系统选择框分支（数据与报告），最近打开列表正确。
