# 界面统一为Animate风格

- 日期：2026-11-10
- 关联步骤：roadmap 第 19 步

## 改动内容

- `web/src/index.css` 改用 Animate UI / shadcn 中性主题变量（白底、中性灰、黑色主色、细边框、0.625rem 圆角、图表色 chart-1~5），引入 `@fontsource-variable/outfit`（开发依赖，构建后随 ui/ 发布）。
- 按钮、卡片、徽标、标签页、对话框、侧边 Sheet、输入框、提示条、筛选按钮、关键词、报告正文改为 Animate UI 组件样式；去掉全局彩色光斑、渐变和大圆角毛玻璃卡片，毛玻璃只保留在吸顶栏和遮罩。
- 图表配色改用 chart 色板；发布时间图的峰值标签移到图上方，不再压住柱子；属地条形图标签列按内容宽度。
- 手机宽度下标签页只显示文字，顶栏不溢出。
- `src/ui/server.ts`：静态资源支持 `.woff2`（`font/woff2`）与 `.svg`，内容安全策略增加 `font-src 'self'`。
- 版本升为 0.0.17。

## 设计决定

- 用户要求整体风格采用 Animate UI，局部可保留毛玻璃；此前只换了组件仍是旧风格，本次统一设计令牌和组件外观。
- Outfit 不含中文字形，中文回退系统字体（苹方 / 微软雅黑）。

## 验证

- 字体 MIME 测试先失败后通过；类型检查（服务端与 web）通过；隔离 HOME 的全量测试 524 项全部通过。
- 浏览器实测 1366 宽与 390 宽：空状态、概况各卡片、原文 Sheet、报告页均正常，无脚本错误，无横向溢出，Outfit 字体已加载。
- 未运行：macOS/Windows 原生文件选择框实机验证、真实模型调用。
