# 桌面打包改在master触发

- 日期：2026-11-14
- 关联步骤：roadmap 第 19.1 步

## 改动内容

- `.github/workflows/desktop.yml`：原型分支 `sea-prototype` 已合入 master，触发条件从“推送 sea-prototype”改为：手动运行；master 推送或 PR 中改动打包相关文件（工作流本身、`scripts/sea.ts`、`scripts/desktop_entry.mjs`、`scripts/desktop_smoke.ts`、`scripts/desktop/**`、`src/cli/desktop.ts`、`src/cli/ui.ts`、`src/ui/instance.ts`）时自动运行。工作流名称改为 Desktop package。
- `docs/roadmap.md` 第 19.1 步：原型状态改为已合入 master，补充新的触发方式。
- `test/scripts/desktop_icon.test.ts`：新增测试，检查触发条件不再引用原型分支，且工作流用到的打包脚本和桌面入口都在触发路径里。

## 设计决定

- 只按打包相关路径自动触发，不是每次推送 master 都打包：每次运行要占用 macOS 和 Windows 运行器，而普通功能改动已有 `ci.yml` 覆盖；需要新安装包时手动运行。随版本发布自动打包是第 19.1 步第 4 项，届时并入 `release.yml`。
- push 与 pull_request 的路径列表直接写两遍，没有用 YAML 锚点，避免依赖较新的解析行为。

## 验证

- `npm run typecheck` 通过；`npm test` 580 项全部通过。
- 工作流 YAML 在本机没有解析器可校验，推送后以 GitHub 是否正常识别触发为准。
