## 设计决定

- 写同一份全局配置，不另建界面专用配置，命令行、MCP、界面行为一致。
- key 只进不出：界面只知道“已保存”，页面、日志和响应都不出现 key。
- key 留空时只在接口地址不变时沿用已保存的 key；改提供商、区域或接口地址后必须重新填写，与配置读取的端点绑定规则一致，防止把 key 发往另一个服务。
- 保存时释放空闲对话而不是全部关闭，避免中断正在生成的回答。
- 未做：界面里删除 key、编辑 `api_key_env`/超时/重试（仍可用配置文件），联网搜索配置。
