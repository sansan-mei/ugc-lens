# 退出移入设置与对话记住文件

- 日期：2026-11-14
- 关联步骤：roadmap 第 19 步、第 19.1 步（退出方式）

## 改动内容

- 退出按钮从顶栏移到设置弹窗底部（“退出 ugc-lens”），所有分栏都可见：`web/src/App.tsx`、`web/src/components/settings_dialog.tsx`。命令行启动提示、`ugc-lens ui --help`（`src/cli/ui.ts`）、dmg 附带的《打开前必读》和 `docs/architecture.md` 的说明同步改为“设置 → 退出 ugc-lens”。
- 对话记住接入的文件：`src/ui/chat.ts` 的对话记录新增 `dataset: { id, path }`，界面带 `dataset_id` 发消息时更新，之后不带数据集的追问保留原值；`src/ui/server.ts` 的 `POST /api/open` 支持 `{ chat: <id> }`，按对话记录重新打开文件。
- 前端：`useChat` 切回历史对话后回调 `onSelect`，`App` 在对话接入过文件且不是当前文件时（`web/src/lib/chat.ts` 的 `needsReopen`）重新打开，停留在对话页并提示。
- `docs/architecture.md` 第 2.1 节“历史对话”补充 `dataset` 字段和按对话重新打开。

## 设计决定

- 退出不放顶栏：用户反馈对话页右上角的电源图标看起来像“停止生成”。停止生成仍在输入框右侧（回答时发送键变为停止键），与常见聊天应用一致；退出是低频操作，放进设置弹窗。
- 按对话重新打开不走“最近打开”白名单：最近打开最多 20 个，旧对话的文件可能已被挤出；路径来自用户自己的对话记录（权限 600），是当时用户选中的文件，所以按对话 ID 直接打开，不接受任意路径。
- 只记录界面接入的文件，不记录模型在对话中用 `load_dataset` 导入的文件：后者可能有多个，且模型下次需要时会自己导入。
