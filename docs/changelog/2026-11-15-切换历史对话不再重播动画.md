# 切换历史对话不再重播动画

- 日期：2026-11-15
- 关联步骤：roadmap 第 19 步

## 改动内容

- 修复：切换历史对话时，整个页面卸载重建并重播进场动画。原因是主内容区动画容器的 key 包含当前数据集 ID，切回对话后自动重新接入文件，key 就变了。
- `web/src/lib/format.ts` 新增 `viewKey`：对话页的 key 固定，其他页仍按“标签页 + 数据集”区分；`web/src/App.tsx` 改用它。

## 设计决定

- 只让对话页不随数据集变化：概况、检索等页换文件时仍需要重新挂载以重置状态。
