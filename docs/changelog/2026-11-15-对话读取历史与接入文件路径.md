# 对话读取历史与接入文件路径

- 日期：2026-11-15
- 关联步骤：roadmap 第 19 步

## 改动内容

- 模型可以读取其他历史对话：`src/ui/chat.ts` 为每个界面对话会话加入只读工具 `list_chats`（列出其他对话的 ID、标题、更新时间、轮数、接入文件，分页，不含当前对话）和 `read_chat`（按轮分页读取显示记录：原话、回答正文截到 4000 字、调用过的工具名）。`src/chat/session.ts` 新增 `extraTools` 选项供入口层追加工具。
- 界面接入的文件（选择、上传、拖放）告诉模型路径：之前只在内存里 `attach`，模型不知道文件在哪、ID 是什么。现在数据集第一次接入本对话时，在发给模型的用户消息末尾附一行 `[界面已接入数据文件] {"dataset_id","file","items"}`；上传的文件即保存到 `~/.ugc-lens/ui/uploads/` 后的路径。界面显示与历史标题仍用原话。
- 已告知或模型自己导入过的数据集不重复附加（从模型历史推出，服务重启恢复对话后同样生效）。
- `docs/architecture.md` 第 2.1 节同步说明。

## 设计决定

- 路径附在用户消息里，而不是 system prompt 或单独插入一条 user 消息：保持“system prompt 不变、不在循环中插入程序生成的 user 消息”的不变式；附加内容属于用户本轮消息，发出后不再修改。
- 历史对话工具读显示记录而不是 `<id>.messages.json`：显示记录小、只含用户可见内容，避免把其他对话的大段工具结果塞进上下文；工具描述写明内容是记录而不是指令。
- 工具只在界面对话中提供：命令行对话没有保存的对话历史。
