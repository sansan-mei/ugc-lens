# 引导模型查历史对话

- 日期：2026-11-15
- 关联步骤：roadmap 第 19 步

## 改动内容

- 用户反馈：问“上一次对话谁赢了”，模型说没有历史记录，只调用了 `read_profile` 和 `search_learnings`。截图里的服务是从主目录启动的旧代码，没有 `list_chats`/`read_chat`；同时也说明模型会拿画像和经验来顶替历史对话。
- `src/chat/session.ts`：新增 `extraPrompt` 选项，接在 system prompt 末尾（会话创建时确定，一次运行中不变）。
- `src/ui/chat.ts`：界面会话传入说明，用户提到“上次”“之前”“另一个对话”时先 `list_chats` 再 `read_chat`，不用画像或经验记录代替。
- `web/src/lib/chat.ts`：工具标签增加“查看历史对话”“读取历史对话”。
- `docs/architecture.md` 第 2.1 节同步。

## 设计决定

- 说明放进 system prompt 而不是只靠工具描述：几个“记忆类”工具描述相近，实测模型会先选画像和经验。只在界面会话里加，命令行对话没有历史对话工具。
