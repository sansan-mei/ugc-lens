- 日期：2026-11-15

## 改动内容

- 全部数据只放在 `~/.ugc-lens/` 一个目录，启动目录只用来解析相对路径和查找数据文件，不再在其中读写 `.ugc-lens/`。
  - `src/config.ts` 新增 `dataDir(homeDir)`；`loadLlmConfig` 不再读取启动目录的 `.ugc-lens/config.json`，删除 `rejectProjectSecret`。`src/web/config.ts` 同样只读全局配置；`src/ui/settings.ts` 不再列出“项目配置”覆盖项。
  - 规则缓存：`defaultCacheDir()` 改为 `~/.ugc-lens/mappings`，所有入口（命令行、界面、对话、MCP、宿主命令）只用这一处。`ChatSession` 与 MCP 服务的 `sharedCacheDir` 选项改为 `homeDir`。
  - 报告 `~/.ugc-lens/reports/`（新增 `defaultReportsDir`）；监听任务 `defaultTasksPath()`、对话监听 `watch-<ID>.json`；联网缓存 `defaultWebCacheDir()`；`analyze_sentiment` 与主题/商业分析的逐条结果；宿主模式 `host/<数据集 ID>/` 输出与界面概况读取的标注结果。
  - 手册与经验合并为全局一份：`playbookPath` 只有 `~/.ugc-lens/playbook.md`，`initPlaybook` 去掉 `global` 参数，待审修改 `playbook.pending.json` 与 `learnings.md` 都在 `~/.ugc-lens/`。`ugc-lens playbook --init` 的说明同步。
  - 界面：报告列表列出 `~/.ugc-lens/reports/` 的绝对路径，并允许打开该目录下的报告；去掉读取启动目录下旧自动分析结果的兼容代码。
- 测试安全：新增 `test/helpers/home.ts`，`npm test`（及 CI 中直接运行的 CLI 测试）用 `--import` 预加载，每个测试进程默认使用临时主目录。
- 文档：`docs/architecture.md` 存放位置表与各处路径、`docs/providers.md` 配置位置与优先级、README、`skills/ugc-lens/SKILL.md`、`AGENTS.md` 测试说明。

## 设计决定

- 按用户要求：工作目录仍可区分（相对路径、画像中的项目条目照旧按目录），但存储只有一个目录；项目经验、项目手册、项目配置合并为全局一份，不再按项目分开。
- 旧数据完全不处理：不迁移也不读取早期写在 `<启动目录>/.ugc-lens/` 的内容，文档说明需要时手动搬到 `~/.ugc-lens/`。
- `loadDataset` 仍保留 `sharedCacheDir` 选项给库调用和测试；`loadLlmConfig`、`loadWebConfig` 保留 `cwd` 参数以兼容调用方，但不再使用。
- 加预加载而不是逐个改测试：默认路径都改到主目录后，任何没显式隔离的测试都会写进本机真实目录，统一在进程级别兜底最可靠。
