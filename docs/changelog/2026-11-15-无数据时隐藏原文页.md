# 无数据时隐藏原文页

- 日期：2026-11-15
- 关联步骤：无

## 改动内容

- `web/src/lib/home.ts` 新增 `visibleTabs(hasData)`：没有数据时不含原文页。
- `web/src/App.tsx`：顶栏标签按 `visibleTabs` 过滤，没打开数据时只显示概况、报告、对话。
- `test/ui/home.test.ts` 新增对应测试。

## 设计决定

- 原文页只用来检索已打开的数据。没有数据时它和概况显示同一个首页，看起来重复，所以直接隐藏。
- 对话里的 `/search` 命令在没有数据时仍可能切到原文页，这时继续显示首页作为兜底，不会落到错误的页面。
- 没有采用“置灰标签”，用户点不进去，反而多一个问号。
